PRESS RELEASE 全店展開キット

株式会社メガネの金剛、全店パソコンへのAI導入と「AI活用 やってみた」掲示板で、現場の工夫が店を越えて回る組織を実現

🏢 株式会社メガネの金剛
☀️
「誰かの『やってみた』が、次の誰かのヒントになる。」
2026年9月1日、大阪・南河内 — 株式会社メガネの金剛（以下、メガネの金剛）は本日、2026年7月下旬から全店（03店・07店・M1・M3）で展開してきた、文字で相談できるAI「Claude Code」導入の現場成果をスタッフ間で共有した。本導入の最大の特徴は、使い方を上から配らず、現場の「やってみた」を持ち寄って広げた点にある。各店のパソコンへの導入後、スタッフはまず「はじめての操作」を試し、サイボウズ掲示板「AI活用 やってみた」に結果を1件投稿する——そこから先は、お客様向けの説明文づくり、メモの表化、接客準備など、それぞれの現場の使い方が掲示板に集まり、ある店の工夫が別の店のヒントになる流れが生まれている。
（リード日付「2026年9月1日」は仮置き。検品で確定してください）

サービスの要約

Claude Codeは、文字で話しかけると文字で答えてくれるAI。店のパソコンに一度入れれば、いつでも呼び出して使える。「遠近両用レンズの説明を、お客様向けにやさしい言葉で書いて」「このメモを表にして」——日本語でそのまま話しかけるだけでよく、専門知識も特別な操作も要らない。

導入は、Googleドライブの「共有資料」フォルダに全店分のインストーラーとやり方ガイドを配置する自己配布型をとった。各店は自分の店のファイルを開き、2つのアプリ（Googleドライブ・Claude Code）を画面の案内どおりに入れるだけで使い始められる。

この導入の主役は、一人ひとりの「やってみた」。サイボウズ掲示板「AI活用 やってみた」は、その使い方が店を越えて広がっていく場になる。入れ終わった日に「はじめての操作」を試し、出てきた答えを掲示板に貼る——これが全員共通の最初の1投稿。2件目からは自由で、うまくいった使い方も、詰まった画面の写真も、どちらも「やってみた」として持ち寄る。誰かの投稿が、次の誰かの「それ、うちの店でもやってみよう」になる。

約束ごとは3つだけ。お客様の個人情報（名前・住所・電話番号・購入履歴）は打ち込まない。出てきた答えは下書きとして、自分で確かめてから使う。詰まったら、画面の写真を1枚、店長か辻へ。判断は、これまでどおり人がする。

課題

これまで、AIは「一部の詳しい人のもの」で止まりがちだった。

「難しそう」で一歩目が出ない層（パソコン控えめなベテラン層）
  • 「パソコンはあまり得意じゃない。AIなんて自分には関係ない」と、最初から距離を置いていた
  • はじめて見る画面——「Windows によって PC が保護されました」の警告、黒い画面のまま2〜3分続く待ち時間——で「壊れた？」「間違えた？」と手が止まりやすい
「時間がない」層（繁忙の中堅層）
  • ただでさえ忙しいのに、新しいことを覚える時間はない
  • 「結局、仕事が増えるだけでは」という警戒
共通の不安
  • 「AIに仕事を取られるのではないか」
  • 「出てきた答えを、そのまま信じていいのか」
  • 一人で詰まったとき、誰に聞けばいいか分からず、そのまま止まってしまう

課題解決

メガネの金剛は、この導入を「ツールの配布」ではなく「現場の工夫が回る仕組みづくり」として設計した。

  1. 「使い方は配らず、持ち寄る」形にした

    中心は掲示板「AI活用 やってみた」。最初の投稿は全員同じ「はじめての操作」で揃え、迷いなく1件目を出せるようにした。2件目からは自由——うまくいった使い方も、詰まった画面の写真も、どちらも立派な「やってみた」。

  2. 最初の一歩を、物理的に軽くした

    インストーラーとやり方ガイドは「共有資料」フォルダに全店分を配置。ガイドは画面の案内どおりに進めば迷わない作りで、警告画面や黒い画面の待ち時間も「正しいファイルです」「ちゃんと進んでいます」と先回りして書いた。

  3. 安心の枠を、先に決めた

    約束ごと3つ（個人情報は打ち込まない／答えは下書き／詰まったら写真1枚で店長か辻へ）。AIが人の判断を代行する仕組みにはしない。

次のステップ

スタッフがAIを使い始めるまでの流れ：

  1. Googleドライブの「共有資料」フォルダから、自分の店の「kongo_ai_install_◯◯.zip」とやり方ガイドを確認する
  2. STEP A：Googleドライブを入れる（自社アカウント optkongo2015 でログイン）
  3. STEP B：Claude Codeを入れる（zipを展開してダブルクリック→数分で完了）
  4. 入れ終わった日に「はじめての操作」を試し、出てきた答えを掲示板「AI活用 やってみた」に貼る（＝最初の1投稿）
  5. 2件目からは自由。困った時・手が止まった時に呼び出し、詰まったら画面の写真を1枚、店長か辻へ

今後の展望

掲示板に集まった使い方は、店長会議や朝礼の場で拾い上げ、「使い方のレシピ」としてやり方ガイドの次の版に還流していく。詰まりの報告が多い箇所は、ガイドそのものを直す。上から教える形ではなく、現場の「やってみた」が積み上がって道具が育っていく形を続ける。

FAQ（Anti-Dead Logic Edition）

現場の言葉を、否定しない。肯定共感→事実→提案の3段で受ける。
Q1.「パソコンが苦手で、難しそう」
❌ Dead Logic（北風）
「大丈夫です、簡単ですよ」
→ 不安な気持ちに寄り添わないまま「大丈夫」とだけ言われても、安心にはつながらない
⭕️ Working Backwards（太陽）
「ですよね、その気持ちよく分かります。だからこそ、やり方ガイドは画面の案内どおりに進めば迷わないように作ってあります。『よくあるつまずき』も先回りして書いてあります。分からなくなったら、画面の写真を1枚撮って、店長か辻に送ってください。それだけで大丈夫です」
Q2.「ただでさえ忙しいのに、仕事が増えるんじゃないですか」
❌ Dead Logic
「効率化できますから、むしろ楽になります」
→ 「今は大変」という実感を素通りしたまま、効果だけを押し付けている
⭕️ Working Backwards
「忙しい中で新しいことを増やすのは、正直しんどいですよね。お願いしたいのは、入れた日の『はじめての操作』の1投稿だけです。そこから先は、困った時・手が止まった時に呼び出す道具として、それぞれのペースで使ってもらえれば大丈夫です」
Q3.「AIに自分たちの仕事が取られるんじゃないですか」
❌ Dead Logic
「そんなことはないです、心配しすぎです」
→ 不安をただ否定するだけで、なぜ大丈夫なのかの説明がない
⭕️ Working Backwards
「その心配、よく分かります。約束ごとの1つに『出てきた答えは下書き。大事なことは自分で確かめてから使う』があります。判断するのは、これまでどおり自分自身です。AIが受け持つのは雑務や下書きで、店頭でお客様と向き合う時間を取り戻すための道具です」
Q4.「警告が出たり、黒い画面のまま止まってる気がして怖い」
❌ Dead Logic
「無視してそのまま待ってください」
→ 説明なしの「無視していい」は、余計に不安になる
⭕️ Working Backwards
「見た瞬間ドキッとしますよね。『Windows によって PC が保護されました』は正しいファイルでも出ることがある表示で、あわてず『詳細情報』→『実行』で進めます。黒い画面が2〜3分続くのも、壊れているのではなく裏側でちゃんと進んでいる状態です。何も操作せず待っていれば『インストールできました』に変わります」
Q5.「お客様の個人情報を入力してもいいんですか」
❌ Dead Logic
「気をつけて使ってください」
→ 何がよくて何がダメか分からないまま、注意だけ促している
⭕️ Working Backwards
「そこは約束ごととして、はっきり決めてあります。お客様の名前・住所・電話番号・購入履歴は打ち込まないでください。レンズの説明文づくりやメモの整理といった使い方であれば問題ありません」
Q6.「出てきた答え、そのまま信じていいんですか」
❌ Dead Logic
「基本的には正確です」
→ 精度を保証するような言い方は、間違っていた時の対応を難しくする
⭕️ Working Backwards
「正直に言うと、答えがまちがっていることもあります。だから、出てきた答えはあくまで下書きとして扱ってください。大事なことは自分で確かめてから使う——この姿勢を崩さなければ、安心して使えます」
Q7.「何に使えばいいのか、正直まだ分からない」
❌ Dead Logic
「いろいろ使ってみてください」
→ 具体例がないと、何から始めればいいか分からないまま止まってしまう
⭕️ Working Backwards
「最初は全員同じです。まず『はじめての操作』をそのまま貼るところから。その先は、掲示板『AI活用 やってみた』を眺めてみてください。他の店の誰かの使い方が、そのまま自分の店のヒントになります」
Q8.「詰まったら、誰に聞けばいいですか」
❌ Dead Logic
「マニュアルを見てください」
→ その場で解決できないから聞きたいのに、振り出しに戻される
⭕️ Working Backwards
「画面の写真を1枚撮って、店長か辻に送ってください。それだけで大丈夫です。詰まりの写真を掲示板に貼ってもらえたら、同じ場所で詰まる次の誰かのヒントにもなります。一人で抱え込まなくていいように、最初からその形にしてあります」
